# Parent Control

**Parent Control** — приложение для родительского контроля на Windows. Оно помогает ограничивать время использования компьютера и блокировать доступ к нежелательным сайтам через брандмауэр Windows.

## Возможности

* **Таймер использования** — отслеживание времени работы ПК с возможностью задать лимит в минутах. При превышении лимита появляется предупреждение.
* **Блокировка сайтов** — добавление доменов в чёрный список. Все IP-адреса сайта блокируются через правила Windows Firewall.
* **Профиль пользователя** — сохранение имён родителя и ребёнка через `QSettings`.
* **Темы оформления** — светлая (**White**), розовая (**Pink**) и тёмная (**Dark**) темы.
* **Статистика** — отдельное окно с текущим временем работы и полем для ввода лимита.

## Требования

* **Операционная система:** Windows (используется `netsh advfirewall`)
* **Python:** 3.8+
* **Библиотеки:** PyQt6
* **Права администратора:** нужны для создания и удаления правил брандмауэра

## Установка и запуск

1. Склонируйте репозиторий:

```bash
git clone https://github.com/mellarii/ParentControl
cd parent-control
```

2. Установите зависимости:

```bash
pip install PyQt6
```

3. Запустите приложение от имени администратора, если планируете использовать блокировку сайтов:

```bash
python main.py
```

Если блокировка сайтов не нужна, приложение можно запускать без прав администратора — остальные функции будут работать.

## Использование

### Главное окно

* **Start / Running / Resume** — запуск, пауза и возобновление таймера учёта времени.
* **Settings** — открытие окна настроек: имена пользователя, тема оформления.
* **Device activity statistics** — окно статистики и настройки лимита времени.
* **Add new sites to blacklist** — окно управления чёрным списком сайтов.

### Блокировка сайтов

1. Введите домен, например `youtube.com`.
2. Нажмите **Add site** — программа найдёт IP-адреса домена и создаст правила брандмауэра для блокировки исходящего трафика.
3. Чтобы удалить сайт из списка, введите его название и нажмите **Delete site**.
4. **Clear url's** — удаляет все сайты из списка и сбрасывает все созданные правила.

### Установка лимита времени

1. Откройте окно **Statistics**.
2. Введите количество минут в поле **Enter time limit (minutes)**.
3. После запуска таймера при превышении лимита появится предупреждение.

### Смена темы

В окне **Settings** доступны кнопки:

* **Pink Theme**
* **White Theme**
* **Dark Theme**

## Структура проекта

```text
parent-control/
├── main.py                 # Точка входа
├── main_window.py          # Главное окно с таймером и кнопками
├── BlacklistWindow.py      # Окно управления чёрным списком (работа с firewall)
├── SettingsWindow.py       # Окно настроек (имена, темы)
├── StateWindow.py          # Окно статистики и лимита времени
├── blacklist.json          # Список заблокированных доменов (создаётся автоматически)
└── updates.txt             # История изменений
```

## Примечания

* Для корректной работы блокировки сайтов приложение должно быть запущено от имени администратора. В противном случае создание правил брандмауэра будет игнорироваться.
* Все правила брандмауэра имеют префикс `ParentControl_Block_` и удаляются автоматически при удалении сайта или очистке списка.
* Таймер не привязан к системному времени — он работает только когда приложение активно и нажата кнопка **Start**.
